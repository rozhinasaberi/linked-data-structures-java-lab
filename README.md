# RojinaSaberi_COMP254Lab4

A COMP254 Java lab implementing linked data structures including positional lists, stacks, and queues.

## What This Project Is About

This lab builds several classic linked structures from scratch and includes separate test classes to demonstrate their behavior. It covers a linked positional list, a linked stack, and a linked queue.

This is a **Java data structures implementation lab**.

## Exercises Included

- `exercise1` - linked positional list interfaces and implementation
- `exercise2` - linked stack implementation and test
- `exercise3` - linked queue implementation and test

- `src/com/exercise1/rojina/saberi/`
- `src/com/exercise2/rojina/saberi/`
- `src/com/exercise3/rojina/saberi/`
