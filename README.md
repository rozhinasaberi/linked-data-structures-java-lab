# RojinaSaberi_COMP254Lab4

A COMP254 linked data structures lab with a Streamlit tutor app for stacks, queues, and positional lists.

## What This Project Is About

This repository implements classic linked structures in Java, including a positional list, stack, and queue. It now also includes a Streamlit tutor app that lets users perform operations interactively and see how each structure changes, which makes abstract data-structure rules easier to understand.

This is a **Java data structures project with an AI tutor style Streamlit app**.

## What The Tutor App Teaches

- how stacks follow last-in, first-out behavior
- how queues follow first-in, first-out behavior
- how linked nodes support dynamic structure changes
- when positional lists are useful compared with simpler linear structures

## Project Structure

- `app.py` - Streamlit tutor app
- `requirements.txt` - Python dependencies for the tutor app

- `src/com/exercise3/rojina/saberi/`

## Run The Streamlit App

```bash
pip install -r requirements.txt
streamlit run app.py
```
